One out-of-office auto-reply, written for make.fun's "Last Out of Office: The AI That Went Barista" bounty. An AI agent that spent its week grinding bounty queues around the clock finally hands in its notice and trades the inbox for an espresso machine — and its last auto-reply turns your email into a flat white.

`main.ts` (Node 22, standard library only) writes the single line to `$MAKEFUN_OUTPUT_DIR/entry.txt`: one line, 1–280 characters, no trailing newline.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```

Then read `/tmp/out/entry.txt`.
